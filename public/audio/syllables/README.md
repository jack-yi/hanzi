# Syllable audio

Drop reviewed MP3 recordings here, named by numbered pinyin syllable:

    yi1.mp3  xue2.mp3  nv3.mp3  (ü → v)

The site automatically plays `/audio/syllables/<audioKey>.mp3` when present
and falls back to browser speech synthesis when a file is missing.

Suggested source: https://github.com/hugolpz/audio-cmn (CC BY-SA — keep the
attribution on the /credits page and review each file before shipping it).
